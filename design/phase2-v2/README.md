# PoladCharkhesh-Nova — Phase 2 V2: visual refinement for Gate 2

Status: ready for Gate 2 review (4 Oct 2026). Gate 2 is NOT approved and Phase 3 has NOT started.
This is a prototype, not the production application: no PHP application, MariaDB schema, Admin
implementation or Publish Engine exists yet.

V1 (the first Phase 2 round) is kept unchanged in `design/phase2/`; this folder is V2.

## What is here

| Path | What it is |
| --- | --- |
| `site/fa.html`, `site/en.html` | One-page prototypes, Persian (RTL) and English (LTR) |
| `site/admin.html` | Admin Control Center wireframes A1–A9 (low/medium fidelity, not implemented) |
| `site/system.html` | Design system v0.3 reference (tokens, palette roles, type and digit rules, components, motion stages, performance ledger) |
| `site/index.html` | Gate 2 review hub with V1→V2 comparison (an HTML fragment: the artifact viewer adds the page skeleton) |
| `site/assets/nova.css` | Design tokens + components (source of truth). The build splits it into inline critical CSS + `nova-rest.css` |
| `site/assets/nova-rest.css` | Deferred (non-render-blocking) part of the stylesheet, generated by the build |
| `site/assets/admin-wf.css` | Stylesheet for the wireframe page only |
| `site/assets/nova.js` | Core interactions (hero bearing response, explorer filtering + "Ask about this code", Exploded Assembly fallback, form validation) |
| `site/assets/ws.js` | Product workspace, loaded only when a product is opened |
| `site/assets/fonts/` | Subset Vazirmatn and JetBrains Mono (both SIL OFL). The Persian subsets carry no Latin letters; Latin islands on Persian pages render in JetBrains Mono |
| `site/data/p/*.json` | Per-product JSON, as the Publish Engine will emit |
| `site/shots-v1/`, `site/shots-v2/` | Screenshots used by the review hub (before / after) |
| `src/` | Templates (`page.html.j2`, `admin.html.j2`, `system.html.j2`, `hub.html.j2`, SVG partials), strings (`strings.py`), sample catalogue (`catalogue.json`), build script (`build.py`) |
| `qa/` | Playwright scripts (screenshots, overflow, axe-core, throttled performance, interaction latency, font audit) and results (`perf-v2.json`, `perf-v1-re.json`, `inp-v1v2.json`) |

## Viewing locally

Module scripts do not run from `file://`, so serve the folder:

```
cd site
python3 -m http.server 8090
# open http://localhost:8090/fa.html
```

## Rebuilding

```
pip install jinja2 markupsafe
cd src && python3 build.py
```

## Measured (Chromium, 390 px phone, 4× CPU slowdown, cache disabled, gzip), V1 → V2

| | fa · Slow 4G | fa · 3G-class | en · Slow 4G | en · 3G-class | Budget |
| --- | --- | --- | --- | --- | --- |
| First-view transfer | 73.6 → 68.8 KB | 73.6 → 68.8 KB | 62.3 → 66.0 KB | 62.3 → 66.0 KB | ≤ 120 KB |
| Requests | 7 → 7 | 7 → 7 | 8 → 8 | 8 → 8 | ≤ 8 |
| First paint = LCP | 0.87 → 0.66 s | 1.75 → 0.83 s | 0.74 → 0.48 s | 1.63 → 0.74 s | ≤ 1.8 s |
| CLS | 0 → 0 | 0.001 → 0 | 0 → 0 | 0.001 → 0 | ≤ 0.05 |

Interaction latency at 4× CPU: first product open 40–64 ms (V1 40–56); re-open 104–128 ms (V1 96–136);
typing ≤ 32 ms (both). All within the 150 ms INP target.

axe-core (WCAG 2.1 AA + best practices): 0 violations on fa light, en light, fa dark, with a product open.
No horizontal overflow at 390 px on fa, en, system, admin and the hub.

wireframes, inquiries, people, counts, times, file names and release IDs are labelled placeholders.
