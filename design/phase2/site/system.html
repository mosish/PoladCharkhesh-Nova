Principles

The website is a numbered set of engineering drawings. Every visual rule below exists either because engineers already read it that way, or because it keeps the page fast on a weak connection.

Drawing, not decorationGraphics follow drafting conventions (line types, sections, dimensions, balloons) and are generated from product data wherever possible.
Two inks on paperNavy ink on paper; bright blue only for interaction and focus; amber only for pending data. Colour always means something.
Codes are sacredPart codes, dimensions and units use Latin digits in monospace, isolated left-to-right, and are never mirrored or translated.
Honest dataVerified and pending are always visible. Pending uses the dashed, hatched "not final" convention, never a hidden footnote.
One page, ten sheetsSections are numbered sheets. Motion only draws, explodes and reassembles; it never hides content or hijacks scrolling outside one stage.
Weight is a design inputEvery decision has a byte and CPU cost, listed in the performance ledger at the end of this page.

Rules

Line heightPersian body 1.85, headings 1.45 (tall ascenders and descenders). English body 1.6, headings 1.15.
No letter-spacing on PersianTracking breaks cursive joins. Uppercase and tracking are for Latin labels and mono captions only.
DigitsPersian prose, counts, sheet numbers and phone numbers use Persian digits (۰۹۱۲ ۷۱۹ ۵۳۱۳); codes, dimensions and units always Latin (6205-2RS · 25 mm). tel: links always Latin.
DatesPersian pages show the Solar Hijri calendar (۱۲ مهر ۱۴۰۵) via Intl in the browser or PHP intl at publish; English pages show 4 Oct 2026.
FallbacksSegoe UI, Tahoma and system fonts behind Vazirmatn; font-display: swap with the Regular weight preloaded. Measured layout shift from the swap: 0.000–0.001.
MeasureRunning text stays within 50–70 characters; headings use text-wrap: balance.

Lines, shape and elevation

Radius 2 pxDrawing sheets have square corners. The only round things are bearings, balloons and status dots.
1.5 px structuralSection rules, sheet heads, inputs, the workspace frame, the action dock.
1 px dividersRows, cells, title-block partitions.
Dashed means "not final"Pending data, empty states, example chips. Never used for decoration.
No shadows, blur or gradientsElevation comes from surface colour plus a border. This also keeps painting cheap on low-end phones.
Focus2 px signal-blue outline, 2 px offset, on every interactive element.

Generated product drawings

Each product's section drawing is built from its boundary dimensions (d, D, B/T/C/H) with the family's template, so a drawing exists even before any photo. Open any product in the prototypes to see one. In production the Publish Engine renders the SVG into the product's HTML.

Mechanics

Logical properties onlymargin-inline, inset-inline-start, border-inline-end, text-align: start; no left/right in the stylesheet except inside drawings.
Isolate, don't flip blocksCodes sit in <bdi dir="ltr"> inside an RTL block, so they keep their order but align to the start of the Persian line.
InputsSearch uses dir="auto": a typed code runs LTR, typed Persian runs RTL; the Persian placeholder is forced RTL and isolates its example code.
Search normalisationPersian and Arabic digits, Arabic ي/ك, spaces, hyphens, slashes and × are normalised, so typing ۶۲۰۵ (Persian digits) finds 6205.
KeyboardArrow keys in the workspace tabs follow reading direction (Left = next in Persian).
Second script on each pageEnglish pages load a Persian-only subset (11.6 KB) so the brand name and family names in Persian shape correctly.

Explorer and workspace

List in HTML, filters in JSEvery published product is a real link in the page (crawlable, works without JS). JavaScript only hides rows; nothing is fetched to filter.
Exact match opensSubmitting an exact code (or a search with one result) opens the workspace directly.
No result is a conversion pathThe typed code is carried into a WhatsApp message and the inquiry form.
Workspace, desktopA sticky panel at the inline end (left in Persian, right in English) with Overview · Drawing · Data · Documents, and a sticky WhatsApp / Call / Inquiry footer.
Workspace, mobileA 92%-height bottom sheet: the page behind becomes inert, Esc / scrim / drag-down / close all dismiss, focus returns to the row.
Deep linksOpening a product sets #p-slug (prototype) — /p/slug in production, server-rendered with the workspace open. The language switch keeps the product.
